# Практична робота №6
 
## Відповіді на запитання
 
### 1. Чому необхідно використовувати clearInterval()?
 
Функція clearInterval() використовується для зупинки таймера, створеного за допомогою setInterval().
Якщо не викликати clearInterval(), то після кожного повторного виконання useEffect() буде створюватися новий інтервал. У результаті одночасно працюватиме кілька таймерів, що призведе до некоректної роботи слайдера та зайвого використання пам'яті.
Тому перед створенням нового інтервалу необхідно очищати попередній

### 2. Чому другим параметром хука useEffect ми передаємо [index]?

Масив залежностей [index] вказує React, що ефект потрібно повторно виконувати після кожної зміни значення index.
Коли змінюється номер поточного слайду, useEffect() запускається знову, очищає попередній інтервал та створює новий з актуальним значенням index.
Завдяки цьому автоматична прокрутка слайдера працює правильно і завжди використовує поточний індекс слайда.
